## Ranked gaps and changes

1. **Question-shaped numerical tasks were routed as ordinary knowledge.** `is_general_knowledge_query` now excludes messages containing both a number and an explicit calculate/compute/convert/multiply action; multi-step numerical requests containing “then” reach the existing planner before the generic “what is” shortcut. Short follow-ups mentioning those actions are no longer classified as plain conversational acknowledgements. Conceptual questions without numeric action remain ordinary chat; the heuristic is intentionally narrow and does not solve general intent classification. Planner output remains untrusted and existing tool registry, schemas, dependency verification, authorization and gates apply.
2. **Approval event prematurely unlocked chat before SSE terminal completion.** The actual ChatView now keeps the message and composer streaming until `done` or error; the pending approval remains visible. A simulated-hook test confirms another send cannot begin while the same stream remains active. Approval acknowledgment does not establish execution; approval resume remains blocked. Mounted scheduling/account-switch behavior is unverified.
3. **Image stream cancellation did not explicitly close its nested engine generator.** The production multimodal SSE wrapper now owns it with `aclosing`, aligning it with other stream wrappers. An immediate-harness test closes the outer production stream after a synthetic delta and observes the inner generator's `finally`; this does not prove real network disconnect or arbitrary provider cleanup.
