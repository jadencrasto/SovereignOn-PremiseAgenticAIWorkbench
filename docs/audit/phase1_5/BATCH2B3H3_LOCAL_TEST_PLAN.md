# Development IPC local test plan

Use only the explicitly requested Python 3.13 environment and a dedicated local development pipe, no production imports, paths, services or configuration. Run a manually started child process with a finite lifetime and explicit teardown. Exercise synthetic JSON only: ping, status, capabilities, unknown command, malformed JSON, oversize, duplicate instance, and restart. Confirm each response says `development_only` and no request carries file or storage data. Test timeout/cancellation using a client that connects and sends nothing. Terminate only the exact child process started by the test if teardown times out. Do not change ACLs outside the newly created pipe's explicit security descriptor; do not change host accounts or firewall. No tests establish trust against another process under the same user, independently verified ACL security, remote-machine isolation, production safety, or full crash and cancellation correctness.
