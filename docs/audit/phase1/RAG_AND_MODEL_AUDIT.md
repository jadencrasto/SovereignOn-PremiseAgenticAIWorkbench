# RAG and model audit

Supported parser extensions are PDF, TXT, MD, DOCX (`backend/rag/ingest.py:66`); CSV/XLSX/image indexing and OCR are not supported by that parser. PDF uses pdfplumber when available with pypdf fallback and page markers (`ingest.py:121`); DOCX extracts text and tables (`ingest.py:395`). Chunking defaults from settings are 800 characters with 100 overlap (`backend/config.py:83`); page hints are inferred (`ingest.py:595`), so citation accuracy needs measurement. Filename and clearance metadata flow through `service.py:396`. Ingestion, deduplication, reindexing and deletion need live validation.

Embeddings use local Ollama nomic-embed-text; Chroma is persisted locally. Semantic search fetches up to max(4K,25) candidates then filters clearance (`retriever.py:117`), which may reduce authorized recall when many inaccessible documents dominate candidates. The fixed maximum cosine distance is **0.385** (`retriever.py:30`), not a universally validated grounding guarantee. Relevance filtering occurs in `engine.py:5439`. No end-to-end hybrid retrieval or reranker established. Retrieval errors return empty results (`retriever.py:130`) and can be indistinguishable from no matches at caller level.

`config/models.yaml` configures qwen2.5:7b, llava:7b and nomic-embed-text; installed versions cannot be determined because loopback connection to Ollama was denied. Router provides capability mapping and model eviction/hardware allocation code (`backend/models/router.py:141,247,277`), but actual concurrency, VRAM, fallback and repeated calls need profiling. Provider abstraction exists (`backend/models/base.py`); model training/customization and reproducible fine-tuning were not established.

Evaluation: `eval/data/qa_set.json` and `eval/rag_eval.py` provide a synthetic labeled starting set, not a representative industrial ground-truth corpus. No fresh Recall@K, MRR, citation accuracy, groundedness, abstention, latency or leakage metrics available. Build versioned, authorized offline fixtures with per-page spans, expected and forbidden sources, paraphrases, no-answer, conflicting and injection cases across formats and roles; measure Recall@K, MRR, citation source/page correctness, claim support, abstention, leakage and p50/p95 latency. Separate synthetic and real-world test sets and never export confidential source content.
